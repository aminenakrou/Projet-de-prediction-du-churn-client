Le Projet

Quatre angles pour
comprendre le churn

01
Dashboard Exploratoire
Visualisations interactives des données brutes — distributions, corrélations, profils clients segmentés. Une analyse en profondeur des 21 variables du dataset Telco Customer Churn.
PlotlyPandasStreamlit
02
Prédiction Individuelle
Formulaire interactif pour saisir le profil d'un client et obtenir sa probabilité de churn en temps réel, avec explication des principaux facteurs de risque.
Scikit-learnPickle
03
Analyse en Lot
Upload CSV ou génération de clients fictifs pour une analyse à grande échelle. Export des résultats avec scores de risque et recommandations d'actions par segment.
NumPyCSV Export
04
Déploiement & CI/CD
Application containerisée avec Docker, pipeline CI/CD via GitHub Actions, déploiement continu sur Streamlit Cloud — une architecture prête pour la production.
DockerGitHub ActionsStreamlit Cloud
